# 阶段4 核心功能实现说明

项目：App Review Planner  
仓库：https://github.com/twostop0-jpg/app-review-planner

## 1. 核心功能实现说明

### 1.1 任务编排（pipeline）
文件：`backend/app/services/pipeline.py`  
七阶段串行执行，每阶段更新 Job stages/artifacts；模型阶段之间间隔约 22 秒降低限流。

### 1.2 采集与清洗
- `collect.py`：US RSS XML → MZStore 回退；sample/import 模式
- `clean.py`：规范化、过滤、去重、cleaning_report

### 1.3 Findings（模型）
- `analyze.py` + `prompts/findings.py`
- 先算统计，再调 Moonshot 生成 JSON
- 证据 ID 不在 cleaned 中则拒绝

### 1.4 PRD（模型）
- `plan.py` + `prompts/prd.py`
- 版本拆分 vNext-1 / vNext-2 / Research
- JSON 失败时规则 fallback，仍挂 finding/review

### 1.5 测试用例（模型）
- `testcases.py` + `prompts/testcases.py`
- 校验 req/review 链接；429 时 fallback

### 1.6 追溯校验（规则）
- `validate.py`：检查全链路与需求覆盖

### 1.7 产品 UI
- `backend/app/web/`：中文页面，创建任务并轮询展示结果
