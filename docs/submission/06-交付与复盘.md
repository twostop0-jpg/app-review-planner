## 2. 验收说明（给评审）

### 2.1 环境准备
1. Python 3.10+
2. `cd backend` → 复制 `.env.example` 为 `.env`，填写 `MOONSHOT_API_KEY`
3. 创建 venv，安装 `requirements.txt`
4. `uvicorn app.main:app --reload --port 8001`

### 2.2 推荐验收路径（离线）
1. 打开 `http://127.0.0.1:8001/`
2. 数据来源选「样例数据」
3. 目标示例：`improve retention and billing clarity`
4. 点击「开始分析」
5. 等待 succeeded

### 2.3 通过标准
- 七个阶段均为完成
- findings、prd.requirements、testcases 非空
- validation 显示通过（ok=true）
- 需求/用例可见关联评论 ID

### 2.4 可选加验
- source=import + `data/imports/example_reviews.csv`
- 更换 goal，观察优先级变化
- （有网络时）source=live

## 3. 复盘总结

### 3.1 做得好的地方
- 规则与模型分工清晰：采集/清洗/校验确定性，语义阶段模型化
- 强证据校验，减少幻觉
- 有 fallback，演示不易因限流完全失败
- 提供无 Node 产品页，降低验收成本
- 提交历史完整，便于展示迭代过程

### 3.2 遇到的主要问题
- Moonshot JSON 不稳定与 RPM 限制
- Windows 端口与路径（CMD 换盘）问题
- GitHub 推送需代理

### 3.3 优化建议（后续）
- Job 持久化（SQLite/Redis）支持重启恢复
- UI 展示清洗报告与统计图表
- 对 fallback 结果做更细的质量评分
- 支持更多导入字段映射与批量对比 App

### 3.4 与岗位相关的收获
完整体验了 Agent/工具链式工作流：目标输入 → 工具化流水线 → 模型推理 → 校验闭环 → 可交付 Demo，贴近 AI Agent 实习中的原型、Prompt、联调与交付要求。

## 4. 本阶段结论
项目已达到可交付状态：文档齐全、主路径可验收、风险已知并有规避方案。
