## 3. 修复说明

### B3 非法 JSON
- 收敛 PRD prompt，限制字符串长度
- `moonshot_client` 增强 repair
- `plan.py` 增加规则 fallback，保证任务可完成且可追溯

### B4 429 限流
- 429 时 sleep 约 22s 重试
- analyze/plan/testcases 之间间隔约 22s
- testcases 失败走 fallback，validate 仍可 OK

### B7 前端门槛
- 新增 `backend/app/web/` 中文产品页
- README 将 `/` 作为主入口

## 4. 联调结论
主路径 sample 全链路可重复跑通；已知缺陷均有修复或明确规避方式。遗留：live 依赖外网质量；低 RPM 下用例可能为 fallback（仍可追溯）。
